# Periodic Table on Homeless Services Categorization

Have you ever wanted to make a periodic table of homeless services? no, just me? 

What happens when we think of how social services have covalent, ionic, metallic, and hydrogenic bonds. 

Maybe case managers working with referrals agencies are like ionic bonds transferring electrons to another and creating attractions between positive and negative ions. And maybe credible messengers and people who have lived a life in people's shoes are the most covalent bonds. 

Maybe a combination of bonds can truly create a responsive network to transfer energy and achieve stability in an everchanging landscape. 

I put this together based on categorization of the "impact categories" in the LA county Regional Plan I built on Airtable. Still need to code out the modals for each of the button to explain what each element is. TBD.
